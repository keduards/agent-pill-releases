# Agent Pill

A small pill that floats above your Mac's windows with one ring for each AI chat: blue while it
works, orange when it needs you, green when it's done.

**[Download Agent Pill](https://github.com/keduards/agent-pill-releases/releases/latest/download/AgentPill.dmg)**,
open it and drag Agent Pill into Applications. The first time, if macOS won't open it, go to
System Settings → Privacy & Security and click Open Anyway. After that it updates itself.

This repository holds only the releases.
